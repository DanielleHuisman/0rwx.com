INTRODUCTION

We need new language to talk about large language models. 0rwx is my attempt.

A labelling system is vital for domain experts talk talk about AI in a clear way. The difference in the 4 levels are not necessarily about what TOOL you use, but your ability to scrutinise the generated work.

I have employed this simple framework to discuss my and other's work with less judgement and confusion, and I hope the 0rwx framework makes it just a little easier for you too. They are:


    ZER0

  • "I think"
  • HAND MADE
  • reading the docs
  • painting w/paint
  • playing music

    READ

  • "I make"
  • BRAINMADE.ORG
  • I write the code
  • reference images
  • chord inspiration

    WRITE

  • "I fix"
  • AI COLLABERATION
  • I read the code
  • generated collages
  • loop generation

    EXECUTE

  • "I curate"
  • 100% AI MADE
  • Vibe coded
  • Image generation
  • Song generation
